# LUT 专业科学质检报告：`broken_dctl_sony_zebra_shadow_33_sony_safe_33.cube`

- **综合评级**：`FAIL`（健康得分：**0 / 100**）
- **目标机内环境**：`sony_cinealta` | **Log 曲线预设**：`Sony S-Log3 / S-Gamut3.Cine (VENICE / FX6 / FX3)`
- **LUT 规格**：`3D=33`，`1D=None`，值域 `[0.0, 1.0]`，TITLE=`broken_dctl_sony_zebra_shadow_33_SonySafe_33`

## 一、核心痛点诊断发现（按严重程度排序）

### 1. 🔴 严重 高光/饱和度单调性反转 (Solarization)
- **上机直接表现**：【斑马纹/等高线条纹元凶】输入亮度升高时输出亮度突然反向跌落，导致渐变高光或亮色带出现暗色条纹！
- **定量检测证据**：在 4 条测试斜坡发现反转，最严重为 [中性灰斜坡] 输入区间 [0.086, 0.888]（累计亮度倒跌 0.1304，最低斜率 -2.27）。
- **达芬奇 / DCTL 修复建议**：重点排查减法饱和度 (Subtractive Sat) / 密度 / Tetrahedral Warper DCTL！减小其高亮通道权重，或在进入 DCTL 前加 CST 开启 Tone & Gamut Mapping。

### 2. 🔴 严重 高频锯齿振荡 (Zebra / Banding 波形)
- **上机直接表现**：【典型斑马纹】输出曲线发生连续正负反复震荡，上机后会在连续影调中渲染出明暗交替的斑马条纹。
- **定量检测证据**：在 [中性灰斜坡] 区间 [0.626, 0.908] 检测到 5 次正负交替锯齿翻转（单步跃迁最大 0.0935）。
- **达芬奇 / DCTL 修复建议**：检查是否忘记关闭 DCTL 的 Zebra / False Color / Gamut Warning 开关，或存在硬阈值分支与过激曲线震荡；可尝试 sanitize_lut.py --de-oscillate 做应急阻尼验证。

### 3. 🔴 严重 3D 色彩空间折叠 (Jacobian det(J) < 0)
- **上机直接表现**：【斑马纹/撕裂条纹元凶】LUT 立方体体素发生三维翻转穿插，插值路径在体素内混乱折返，产生网状/条纹裂变！
- **定量检测证据**：共 1660/32768 个体素 (5.066%) 发生空间折叠，最小归一化 det(J)=-1.0671，最严重坐标≈[0.7812, 0.2812, 0.7812]。
- **达芬奇 / DCTL 修复建议**：排查高曲率 Hue-vs-Hue / Tetrahedral Color Warper / 极度色相挤压 DCTL，减小色相交界处的扭曲幅度。

### 4. 🔴 严重 极暗部近轴色度爆炸 (Shadow Chroma Explosion)
- **上机直接表现**：【极暗部彩噪/杂色斑元凶】在黑电平附近微小传感器热噪触发极高色度增益，画面暗部出现蠕动红/绿/蓝彩噪颗粒！
- **定量检测证据**：在输入暗部近灰轴检测到 2 个色度爆炸体素，最大近轴色度增益=3.46x（输出色差达 0.216，坐标 [0.0625, 0.125, 0.0938] -> 输出 [0.0, 0.216, 0.0954]）；黑位底噪仿真显示色度噪点相对标准曲线放大 4.05 倍！
- **达芬奇 / DCTL 修复建议**：典型成因是 DCTL 在暗部计算饱和度/球面坐标时分母接近 0（如 1/(L+1e-4)）。请在 DCTL 内对暗部分母加安全下限（或 smoothstep 渐弱暗部饱和度），并在 Resolve 暗部做 Shadow Desat；应急上机可用 sanitize_lut.py --tame-shadow-chroma。

### 5. 🔴 严重 极暗部亮度增益斜率尖峰 (Shadow Slope Spike)
- **上机直接表现**：【极暗部颗粒粗噪点元凶】黑电平附近的微弱传感底噪被陡峭斜率等比例放大，产生明显暗部亮度颗粒感。
- **定量检测证据**：极暗部 (0.0~0.17) 最大亮度斜率=1.96 (在输入 0.094 处)，单通道最大斜率=2.38，黑位亮度底噪相对标准曲线放大 4.09 倍。
- **达芬奇 / DCTL 修复建议**：检查是否重复叠加了两次 S-Log3->709 转换或暗部 Contrast/Pivot 过激；建议放松阴影 Toe 对比度并核对 S-Log3 黑位 (95/1023) 对应斜率。

### 6. 🟠 警告 四面体 vs 三线性插值严重分歧
- **上机直接表现**：【所见非所得条纹】在 Resolve 默认四面体插值下看似正常，导入三线性插值的机内监看后却裂开色阶或条带！
- **定量检测证据**：体素中心最大差异 ΔRGB=0.0850 (位于 [0.0469, 0.1094, 0.0469])，P99 差异=0.0336。
- **达芬奇 / DCTL 修复建议**：在 DaVinci Resolve 的 Project Settings 中将 '3D Lookup Table Interpolation' 临时切为 Trilinear 即可在监看器上复现该差异，适当缓和该色彩区域的局部急转斜率。
